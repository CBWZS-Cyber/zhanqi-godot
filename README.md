## 一、项目结构

```
zhanqi-godot/
├─ project.godot           # 引擎配置（Godot 4.7 / Forward Plus；主场景 MainUI）
├─ scenes/                 # 场景：MainUI(总菜单) / Duel(1V1 对局) / TeamDuel(4V4 可玩对局) / Board(标准棋盘展示)
├─ scripts/
│  ├─ global.gd            # autoload 全局状态（battle_mode: 1v1|4v4、offline_type: pve|hotseat）
│  ├─ board.gd             # Node2D 棋盘绘制（1V1 3×3+翼 / 4V4 8×8+左右翼 4 出生格）
│  ├─ ui/                  # duel.gd(1V1 交互对局) / team_duel.gd(4V4 可玩对局)
│     │                       # main_ui.gd(菜单导航) / battle_hud.gd(右侧信息栏)
│     │                       # unit_token.gd(棋子牌) / start_menu.gd
│     │                       # team_board.gd(4V4 自绘棋盘) / settings_layer.gd(局内设置+Bug上报)
│  └─ combat/              # 战斗层（纯逻辑，无节点）
│     ├─ battle.gd         # 1V1 战斗管理器（2 棋 / 5×3 格）
│     ├─ battle_team.gd    # ★ 4V4 战斗管理器（8 棋 / 10×8 标准棋盘，2026-09-05 新增）
│     ├─ battle_unit.gd    # 棋子运行时（hp/energy/盾甲/速度/状态/资源池/层数规则）
│     ├─ hero_defs.gd      # 英雄登记表（龙王/剑舞/邪神/光雨/药师/追猎/孤狼/rapper/仙尊/灵虚/辛克莱）
│     ├─ skill.gd          # 技能运行时（冷却/耗能/效果调用）
│     ├─ skill_effects.gd  # 技能元信息 DATA + 效果函数 EFFECTS（含 speed_order 排序）
│     ├─ ai.gd             # BattleAI（1V1/4V4 共用决策：plan_move / plan_skill）
│     └─ grid_board.gd     # 通用格图 BFS/可达模块（待接入战斗层）
├─ tests/                  # 回归测试（headless -s 运行）
│  ├─ combat_regression.gd    # 1V1 战斗层回归（61 断言）
│  └─ team4v4_regression.gd   # ★ 4V4 战斗层回归（52 断言，2026-09-05 新增）
├─ maps/ / tools/ / installer/   # 地图文件 / 编辑器工具 / 安装脚本
```

## 三、运行与测试

- 运行：Godot 打开 `project.godot`，或导出后运行。
- 无头冒烟：`godot --headless --path . --import` 后 `--quit-after 2` 无 ERROR 即通过。
- 1V1 回归：`godot --headless --path . -s res://tests/combat_regression.gd`
- 4V4 回归：`godot --headless --path . -s res://tests/team4v4_regression.gd`
- 退出码 0=全过；1=有失败。

## 四、注意点

1. **版本命名**：主程序压缩包用 `日期+版本号`（如 `9.05代码_v1.zip`），禁止无声覆盖旧版本；改主程序前先备份。
2. **回合结构（1V1 与 4V4 一致）**：每棋每回合 = 1 移动权（8 方向 1 格）+ 1 技能权（先移后放、可放弃）；同回合内所有存活棋按实时速度从高到低依次行动；速度变化立即影响后续顺序。
3. **出生与棋盘**：1V1 = 3×3 主区 + 左右翼各 1 出生格；4V4 = 8×8 主区（x1..8,y1..8）+ 左翼红方 4 出生（x0,y3..6）/ 右翼蓝方 4 出生（x9,y3..6）。棋盘格 x0..9/y1..8 均可通行（翼列可走入）。
4. **4V4 v1 已知边界**：技能目标暂统一"单目标"（AI 选最近、玩家点选）；范围/多目标后续声明式补。**数值未平衡**：英雄普伤 1~3 vs 护甲 1~3，护甲为固定减伤，AI 全自动局常出现"互相打不动→80 回合僵局"，属已知现象，后续统一调数值。
5. **伤害口径**：普伤=盾先吸→甲减免→扣血；真伤走 lose_hp 无视盾甲；百分比伤害未标真伤按普伤结算。
6. 英雄 hp 为小数值制（6~10），盾/甲/伤害同样小数值，调数值时注意整体比例。
7. **最高难度（困难·战术模型）**：豆包每回合做「选择题」（A进攻/B稳守/C保命）+ 填「战术倾向」（focus集火/posture姿态/protect保护）；规则 AI 据此调权重后精确执行，失败自动回退本地 hard。API Key 以混淆加密随包（ai_key.bin），仅本地解密；离线/断网时困难自动用本地 AI。
