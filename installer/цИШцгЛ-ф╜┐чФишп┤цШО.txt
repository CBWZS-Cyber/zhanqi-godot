【战棋 1.2 公网联机版 - 使用说明】

一、安装
1. 双击"战棋安装包_1.2_公网联机版_20260905.exe"
2. 若 Windows 弹出蓝色拦截框（SmartScreen）：点"更多信息" → "仍要运行"
3. 若杀毒软件报"木马/风险程序"：这是无签名程序的常见误报，本程序不含病毒。
   处理：在杀软弹窗点"信任/允许"，或到隔离区恢复并添加信任。
   （安装程序已做代码签名，安装证书后可完全放行，见下）

二、（可选，推荐）安装签名证书，杀软永久放行
1. 双击"战棋证书.cer" → "安装证书" → "本地计算机" → "将所有的证书都放入下列存储"
   → 浏览选择"受信任的根证书颁发机构" → 完成
2. 装完后 Windows Defender 对本程序显示签名有效，不再拦截

三、联机对战
【局域网（同一宿舍路由器/同一热点）】
  一人：联机模式 → 局域网对战 → 建房
  另一人：联机模式 → 局域网对战 → 加入房间 → 输对方 IP（建房方 cmd 里 ipconfig 查看 IPv4 地址）

【公网（不在同一网络）】
  建房方：联机模式 → 公网对战 → 建房 → 等"房间号已生成" → 点"复制房间号"发给对方
  加入方：联机模式 → 公网对战 → 加入房间 → 粘贴房间号 → 连接
  ※ 公网建房方需要 cpolar 账号（免费注册 cpolar.com，把 authtoken 配置到 ~/.cpolar/cpolar.yml）
  ※ 加入方无需任何配置

【4V4】支持蛇形选秀，双方轮流点选英雄

四、杀毒软件报毒处理（重要！360 用户必看）
若"公网建房"提示"cpolar 进程被中止"或房间号生成后突然失效：
→ 是 360 等杀软把内网穿透工具（cpolar）当风险程序反复拦截所致
→ 解决：打开 360 安全卫士 → 木马查杀 → 恢复区 → 找到 cpolar 相关 → 恢复并信任
→ 并到 360 设置 → 安全操作中心/信任区 → 添加游戏安装目录为信任目录
→ 完成后重新建房即可

五、常见问题
- 提示"获取房间号超时"：检查网络；或免费隧道配额被占，稍等 1 分钟再建房（游戏会自动清理残留）
- 对方断线：判在线方获胜
- 防火墙首次提示：允许访问网络
