操作说明

从中央 (0,0) 的格子开始设计。
铺格 / 涂地形：
· 空白处左键 = 新建一个格子（任意位置都行，不必贴着已有格）
· 已有格上左键 = 换成当前地形
· 右键 / 删除工具 = 删掉格子
出生点（专属）：选阵营 → 选单位（可＋加） → 点格子放该棋子的专属出生点；同单位再点别处会自动搬家
右键 = 删格子；出生点工具下右键只清出生点
滚轮缩放 · 空格/中键拖 = 平移
Ctrl+Z / Ctrl+Y = 撤销 / 重做
